HOW IT WORKS

Alert to PR in three tiers

01
Alert ingestion
PagerDuty fires. Quisac receives the webhook and maps the failing service to a node in your dependency graph.
webhook

02
Graph traversal
BFS from the failing node. Candidate files ranked by distance, fault history, and last modified.

Pattern match
Check if this incident matches a known pattern. If yes, cached fix is applied immediately.
